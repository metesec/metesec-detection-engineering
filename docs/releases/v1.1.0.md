# Version 1.1.0 — reviewed enterprise baseline

Status: local release candidate; not published and not deployed.

All fifty existing rules were reviewed. Seventeen of fifty supplied additional
concepts were admitted after rework; thirty-three remain explicitly deferred.
The overlapping hardened archive was treated as an alternative implementation,
not another twenty-three logical rules. The pack contains 67 Sigma packages,
66 Sentinel preview bindings and ten source contracts.

Local verification: 115 Python and 19 JavaScript unit tests, 264 positive and
441 negative synthetic rule cases. The complete aggregate check passes both in
the working tree and from a freshly extracted source archive with frozen
JavaScript dependency installation. Deterministic rebuild tests pass.

Important fixes include argument-bound Defender and firewall switches, valid
ProcDump default dumps, separate BITSAdmin job operations, meaningful registry
write filters, tighter task/MSI/Run-key arguments and structural delegated-grant
normalization. Benign administrative signals have more conservative severity,
confidence and descriptions. Stable logical identities are preserved.

New gates cover duplicate YAML keys, metadata/ATT&CK consistency, unique Sigma
UUIDs, canonical sources, fixture ownership, explicit review/provenance and
revision-bound promotion evidence. Regex and boolean tests are bounded and do
not substitute for live Kusto testing. Scheduling validates duration ranges and
derives an ingestion-aware window from disabled pilot settings.

The source archive now includes the tooling, pinned dependency declarations,
shared tests, contracts and documentation needed to validate and rebuild it.
The earlier published v1.0.0/v0.1.0 tags and artifacts remain unchanged.

No current revision is production-certified. No deployment, external publication,
new Forgejo CI run or live target validation is claimed by this local release.
See the [adoption guide](../enterprise-baseline.md), [full reviews](../reviews/)
and the generated catalogue for current counts and per-rule limits.
