# MeteSec Detection Pack v0.1.0

This is the first checksummed public release of the Detection-as-Code functional
foundation.

## Included

- five experimental logical detections with portable Sigma implementations;
- fifteen positive and twenty negative synthetic fixture cases;
- deterministic machine-readable and human-readable catalogues;
- four explicit Microsoft Sentinel preview bindings across `SigninLogs` and
  `AuditLogs`;
- four reviewed Golden KQL snapshots;
- the versioned schemas, contracts, security policy and Apache-2.0 license;
- an internal manifest containing the SHA-256 digest of every packaged source.

## Important boundaries

- The detections remain experimental and require environment-specific review.
- Synthetic fixture matches prove only the documented bounded local evaluator.
- Golden KQL proves deterministic preview compilation, not production behavior.
- `MSEC-DET-0001` has no Sentinel binding because the verified target contained
  no suitable Windows event telemetry.
- The archive contains no deployment template, credential, customer data, live
  telemetry or production approval.

## Integrity verification

Download the ZIP and `SHA256SUMS` into the same directory, then run:

```console
sha256sum --check SHA256SUMS
```

The expected result is `metesec-detection-pack-v0.1.0.zip: OK`. The checksum
verifies the downloaded bytes; it is not a cryptographic authorship signature.
