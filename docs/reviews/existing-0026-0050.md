## Evidence basis

The most significant corrected assumption is ProcDump's default mini dump:
Microsoft documents a process name without a size switch as a valid dump
command. The old negative fixture contradicted that documented behavior.
[Microsoft ProcDump documentation](https://learn.microsoft.com/en-us/sysinternals/downloads/procdump).

The firewall correction follows the parameter-level distinction between Enabled
and other GpoBoolean options such as LogBlocked. A false value on a different
parameter does not disable the firewall.
[Microsoft Set-NetFirewallProfile reference](https://learn.microsoft.com/en-us/powershell/module/netsecurity/set-netfirewallprofile?view=windowsserver2025-ps).

SC accepts its remote server argument separately from the executable path;
Windows Installer takes a package argument for its installation operations;
InstallUtil distinguishes assembly arguments from named installer options.
These contracts support binding the observed strings to their intended arguments.
[SC create](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/sc-create),
[Msiexec](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/msiexec),
[InstallUtil](https://learn.microsoft.com/en-us/dotnet/framework/tools/installutil-exe-installer-tool).

Existing upstream behavior references remain in the rules. This review did not
import SigmaHQ source text. Similar public techniques are expected and are not
treated as a defect; attribution and the implemented semantics are separate
from novelty.
