# Review of existing detections 0001–0025

Reviewed 2026-09-11. All 25 authored rules, logical manifests and original local
fixtures were inspected. Stable identities are preserved and every rule remains
experimental. These are enterprise baseline candidates, with an explicit split
between suspicious behavior, vendor risk signals and ordinary change monitoring.
No live telemetry or execution was collected for this review.

| ID | Assessment and resulting change | Deployment consideration |
| --- | --- | --- |
| MSEC-DET-0001 | Match the leading service executable path, not a temporary directory in a log argument. Add quoted-path and missing-path regressions. | Suspicious behavior; installers can still qualify. Intentionally lacks a Sentinel binding. |

| MSEC-DET-0019 | Retain the two successful federation/domain-authentication operations; lower confidence to medium. | Sensitive change monitoring; certificate rotation and federation migrations are expected matches. |

| MSEC-DET-0022 | Retain successful strong-authentication disablement; lower confidence to medium. | Sensitive change monitoring; does not cover every MFA control or establish a Conditional Access bypass. |

The review expands this range from 175 to 231 synthetic cases. All 231 expectations
pass with the repository evaluator, including raw serialized JSON fixtures for
0021 that exercise property order, JSON-quoted new values, misleading target names,
old values, cross-resource combinations, duplicate properties, wrong target types
and malformed input. Command-line checks cover semantics visible in a string;
they are not shell parsers and do not prove execution or resist every obfuscation.

Primary references used for substantive changes:

- Microsoft documents separate BITSAdmin [addfile](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/bitsadmin-addfile) and [transfer](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/bitsadmin-transfer) commands.
- The [PowerShell CLI reference](https://learn.microsoft.com/en-us/powershell/module/microsoft.powershell.core/about/about_powershell_exe) and [PowerShell host parser](https://github.com/PowerShell/PowerShell/blob/master/src/Microsoft.PowerShell.ConsoleHost/host/msh/CommandLineParameterParser.cs) define encoded-command arguments and supported abbreviations.
- [Set-MpPreference](https://learn.microsoft.com/en-us/powershell/module/defender/set-mppreference) identifies Boolean disable parameters and exclusion-value parameters.
- [Certutil URLCache](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/certutil#-urlcache) distinguishes cache operations and forced URL fetching.
- [Wbadmin system-state deletion](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/wbadmin-delete-systemstatebackup) and [reg save](https://learn.microsoft.com/en-us/windows-server/administration/windows-commands/reg-save) establish the supported command forms.
- Microsoft's [application security operations guidance](https://learn.microsoft.com/en-us/entra/architecture/security-operations-applications) describes privileged delegated scopes and AllPrincipals consent. Its [Sentinel rule](https://github.com/Azure/Azure-Sentinel/blob/master/Solutions/Microsoft%20Entra%20ID/Analytic%20Rules/AzureADRoleManagementPermissionGrant.yaml) demonstrates structural inspection of ServicePrincipal modifiedProperties new values.
- The [Entra audit activity reference](https://learn.microsoft.com/en-us/entra/identity/monitoring-health/reference-audit-activities) provides documented operation names; consumers must still validate their tenant's current schema and audit coverage.

These sources support the documented semantics. They do not establish universal
false-positive rates, production validation or copyright clearance; provenance
and upstream similarity are reviewed separately.
